The Ritual

Slot. Click. Run.

01

Slot

Pull the disk from its sleeve. The label reminds you which function lives on this one.

02

Click

Push it into the frame. Pogo-pins engage with a satisfying click. The frame lights up.

03

Run

The function comes online — charger, drive, audio, whatever this disk holds.

Why it matters

Modular systems print money.

Drop in a disk and the function comes online. No menus. No setup. Just clack.

Stackable

Frame stacks vertically. Build a tower of functions or keep one disk active at a time.
